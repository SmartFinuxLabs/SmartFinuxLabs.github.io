Fiat Redemption Architecture & Interfacing Overview

When the Router selects a Fiat Redemption Route, the platform converts digital asset balance in the Source ADA (e.g., `ada_cust_usdc_01`) into a fiat payout to a Destination Fiat Account / ADA (e.g., `ada_cust_fiat_usd` or External Bank Account via Fedwire / ACH / Circle Fiat).

Treasury Position Calculator Liquidity Guard

Double-Entry Ledger Engine Append-Only

Source ADA (USDC Account) Subledger Account

Subledger ADA holding digital assets. Encumbers $10k during redemption phase.

Financial Journal DB Immutable Audit

Stores append-only financial journals. Debits equal credits at all times.

3. Banking & Fiat Settlement 🏛️ Banking Rail
Banking Submitter Service Payout Worker

Pipes payout instructions to commercial bank host-to-host API / ISO20022 wire gateway.

Fedwire / ACH Settlement Rail External Banking

Executes wire transfer from platform custody bank to recipient's Chase account.

Bank Webhook / Statement Rx Ingress Statement

Ingests BAI2/CAMT.053 bank confirmation files and real-time wire status webhooks.

Fiat Reconciliation Engine Match & Clear

Matches Federal IMAD/OMAD reference numbers against instruction IDs to finalize settlement.
